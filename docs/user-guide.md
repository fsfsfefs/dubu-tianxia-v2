# 读步天下使用指南

第二版 · 入门与功能手册 · 更新于2026-11-02。用同一份教材，把阅读、提问、总结和复习连起来。

## 01 · 第一次使用：从这里开始

### 用途
快速走通“导入教材 → 阅读 → 提问 → 保存 → 复习”的完整路径。只阅读 PDF、搜索、标注和手写笔记，不需要聊天模型 API Key。

### 用法
1. 在“学习空间”点击“＋ 导入教材”，选择本地 PDF。点击书架中的“打开”进入教材总览，再点击“继续 PDF”进入阅读器。
2. 如需 AI，在“模型配置”填写服务地址、模型名称和 API Key。可先点“测试连接”，再点“保存并设为默认”。第二版的模型密钥独立配置，第一版密钥不会自动复制。
3. 阅读时点击“AI助读”。选中文字后解释局部内容；切到“单书全文”则在下方输入问题，系统检索教材原文后回答。
4. 点击“保存解释”收入笔记；或者在“练习”中打开题目卡，标记“已掌握”或“还需复习”。
5. 在“学习记忆”按教材回看内容；定期通过“更多设置 → 完整备份”下载完整 ZIP。

### 现有功能总览

- 教材管理：PDF导入、书架与文件夹、阅读进度保存；从总览查看教材结构，从学习记忆回看笔记与练习。
- 阅读与目录：连续翻页、缩略图、关键词搜索、本地中英文OCR；优先原有目录，无目录时可用AI生成草稿并人工校对。
- 鼠标与二合一电脑：Ctrl＋滚轮缩放、可选直接滚轮缩放、双指捏合及单指拖动；功能栏可收起，阅读与助读区域可调整大小。
- 标注与便签：文字高亮、整页星标、正文和左右留白手写；区域标记可命名、跳页、删除；页边便签可粘贴图片并长期保存。
- AI助读：Assistant阅读解释、Master长期文字对话，支持当前原文、单书全文、多书联系，以及图片提问、导读、行间教学、深度问答和可选联网查证。
- 章节与全书结构：每书独立选择已保存模型，最多3本同时总结；可导入外部结构与人工总结，点总结页码跳回PDF并返回原总结。
- 练习与任务：框选文字识题、问答卡、掌握状态与复习次数；后台任务可暂停、取消、重试及逐条删除，已完成成果保留。
- 数据迁移：单书全部数据ZIP、整库完整备份及旧版数据兼容；Windows桌面版与网页数据独立，可通过备份迁移。

阅读、OCR、标注、便签、已保存内容查看和备份不需要聊天模型密钥。AI问答、AI目录和结构生成需要配置可用模型；图片提问还需要模型支持视觉输入。下面各章给出操作入口、限制及保存范围。

### 随时查阅
首页“打开使用指南”、顶部“使用指南”和阅读器工具栏的“使用指南”均打开本手册。目录可定位章节，搜索框可查找功能或使用条件；关闭手册后继续原来的页面。

## 02 · 书架、教材和文件夹

### 用途
集中管理本地教材，按学习主题分组，并从上次阅读位置继续。

### 用法
- 导入：点击“＋ 导入教材”。在某个文件夹下导入，教材会归入该文件夹；目前支持 PDF。
- 打开：点击教材行的“打开”先看总览；首页“继续学习”直接进入当前教材阅读器。
- 整理：点击“＋ 新建文件夹”；文件夹旁的更多操作可重命名、删除。教材行的更多操作可重命名、移动文件夹、查看全书结构或删除。
- 分类菜单：点击文件夹右侧“···”打开重命名/删除菜单，菜单显示当前分类名称；点空白或按Esc关闭，也可用上下方向键选择。分类较多时自动换行。
- 筛选：点击“全部教材”、某个文件夹或“未分类”。删除文件夹不会删除里面的教材，教材回到未分类。
- 返回：使用页面的“返回”按钮在学习空间、总览、阅读和学习记忆之间返回。

### 注意
删除教材会同时清理其关联学习数据。需要保留时先做完整备份。文件夹和教材数据保存在本机，两版项目的数据不会自动互相同步。

## 03 · PDF 阅读、目录、搜索和 OCR

### 用途
连续阅读原始 PDF，找到章节或关键词，并将扫描页转换成可选文字。

### 用法
- 翻页：连续向下滚动，或使用顶部页码输入、上一页和下一页。普通打开会恢复上次页码、页内位置和缩放；引用、搜索等指定页跳转优先。
- 定位：点击“目录”查看已保存校对目录或 PDF 原有书签；点击“页面”查看缩略图。缩略图上的星标可标记整页。
- 搜索：点击放大镜“书内搜索”，输入原文关键词并点击“搜索”；点击结果返回对应 PDF 页。清空或关闭搜索可结束本次搜索。
- 文字：有原生文字层的 PDF 可直接选择。扫描页会自动进行本地中英文 OCR，等待状态显示“OCR 文字可选”后再选择或框选。
- 滚轮缩放：在PDF区域按住Ctrl滚动鼠标滚轮（上滚放大、下滚缩小），也支持触控板发出的Ctrl滚轮捏合事件。默认普通滚轮上下阅读；需要直接滚轮缩放时，在“更多阅读工具”勾选“滚轮直接缩放”，本机会记住开关。范围50%—300%。
- 触屏缩放：双指在PDF区域张开放大、合拢缩小，单指可拖动阅读；“标注”或框选模式下，单指执行所选工具，双指改为缩放并取消未完成的触摸笔画。勾选“仅手写笔”后，可用笔写画、手指拖动。笔落下时掌触不会触发缩放。手势结束后画面重新清晰，放大后可横向拖动查看左右边缘，功能栏收起时同样可用。
- 显示：在工具栏“更多阅读工具”中缩放、点击“适应宽度”恢复100%，或开启“柔和纸色”。窄阅读区工具栏自动换行。

### 使用条件
OCR 和全文补读可能耗时，需要本地 OCR 资源已安装。搜索最多显示 80 个匹配页面。这里的页码指 PDF 文件实际页序，可能与纸面印刷页码不同。索引成功只表示已提取或复用了文字，不代表已有章节目录。没有 PDF 书签时，可生成AI目录草稿或导入外部结构，再人工校对；印刷目录页通过原文/OCR提供线索，不等于可直接使用的电子目录。

### 原有目录、AI目录和人工校对

总览与PDF阅读器使用同一份目录。优先使用已保存的校对/导入目录，否则读取PDF原有电子书签。书中印刷的目录页可以作为AI还原目录的依据，文字索引成功并不等于已有电子目录。

在总览点“生成 / 编辑目录”或“编辑 / 校对目录”，也可在PDF“目录”侧栏打开编辑器。原有目录可直接校对，不调用AI；没有目录时选择已保存模型，点“AI生成目录草稿”。程序先准备全书原文，扫描页复用本地OCR；再用一次模型调用生成草稿，需要有效API Key。取消可停止后续准备或忽略返回，已经发出的模型请求不保证停止计费。目录模型生成单次最多等待5分钟，界面显示已等待秒数；超时保留现有编辑内容，不自动重复调用，可检查连接或切换模型后手动重试。

逐项修改章节标题、实际PDF页码（从封面算第1页）、从0开始的层级，支持添加、删除、上移、下移。“校对原文”显示对应页面，可手动切换预览页。保存前检查页码按阅读顺序排列，首项层级0，后续层级不跳级。保存后总览与阅读器同步使用；关闭未保存草稿不会替换正式目录。后台任务处理本书时须先暂停并等当前分块结束；目录被其他页面修改时需重新打开编辑。

AI目录限3000页，读取前20页较长摘录及全书每页开头，长文有截断，模型可能遗漏或误判，必须核对。目录修改后旧总结会保留，但章节范围键可能变化，需要为修改后的章节重新生成总结。目录随单书/完整备份迁移；原PDF文件不修改。当前仍只支持PDF导入，其他格式需先转换为PDF。

## 04 · 文字高亮、手写标注和页边便签

### 用途
在原文旁留下重点、图示和短笔记，方便回看。

### 用法
- 文字高亮：选中原文，在浮动菜单中保存高亮。通过“高亮管理”搜索、定位、改色、添加备注与标签或删除。
- 整页星标：在“页面”缩略图上点击星标；可在高亮管理中回到标记页。
- 整页标记：一整页的全部手写痕迹计为一个标记，包含正文和左右留白；同页相距很远的笔画也合并。标注旁数字显示当前页是否有标记（0或1），标记列表按有笔迹的PDF页展示，可统一命名、跳页、删除该页全部手写（可撤销）。文字高亮及星标不受影响，不再提供同页“新建标记”。旧笔迹无需重绘，旧页多个名称可通过一次命名统一。
- 手写：点击“标注”，选择画笔或荧光笔，调整颜色与粗细后在页面落笔。支持鼠标、触控或触控笔；“完成”退出绘制模式。
- 修改：选择橡皮擦，按住鼠标、手指或笔连续擦动，经过的位置会即时消失，松开后保存；拖动“橡皮大小”调节8—80px直径，圆圈显示范围，偏好自动记住。点击“撤销 Ctrl+Z”或使用 Ctrl+Z 撤销整次擦除。选中文字创建的高亮请在“高亮管理”中删除。
- 二合一电脑手写笔：进入“标注”后，笔尖使用当前工具；有笔尾橡皮时可翻转擦除，支持标准侧键的笔可按住侧键临时擦除、松键继续书写。勾选“仅手写笔”可防止手掌和手指写画，鼠标仍可操作；笔在操作时也会忽略触摸干扰。
- 便签：点击“便签”，给当前 PDF 页添加、编辑或删除图文便签；图片操作和20MB限制见下方说明。

### 使用条件
标注和便签保存在本机。手写撤销最多保留当前阅读会话的 80 步，不是跨重启的编辑历史。框选识题与手写绘制是不同工具，使用一个时会退出另一个。

手写笔按钮取决于硬件及Windows驱动向WebView2提供的笔事件；蓝牙顶部快捷按钮不属于侧键，若系统把按钮分配给其他应用，请使用工具栏橡皮擦。当前笔宽由“粗细”控制，不随压感变化。橡皮大小按屏幕CSS像素计算，PDF缩放后仍保持同样的屏幕擦除直径。

### 页边便签图片与左右留白手写

阅读器“便签”中可直接粘贴剪贴板图片，或点击“添加图片”上传PNG、JPEG、WebP、GIF。支持只有图片的便签；图片可预览、移除，编辑完成后点保存。单张及一条便签内所有图片的原文件大小合计不得超过20MB，不自动压缩。图片未保存前切页或关闭面板会清空草稿。图片保存在本机学习数据库，不发送给模型，笔记删除时一起删除。

图片会随完整备份ZIP和单书完整备份迁移；有图片的单书包采用格式2，需使用新版导入，无图格式1及历史包仍可导入。Markdown笔记导出仅文字；要完整迁移图片请使用ZIP。

点击“标注”后，PDF两侧现有空白显示左右手写区，可用画笔、荧光笔、橡皮擦和撤销。两侧及PDF正文分别记录，擦除不跨区域影响其他笔迹，刷新后保留。留白随窗口和PDF缩放变化；窗口较窄或PDF放大后无留白时，缩小PDF或加宽阅读区域即可再次看到原笔迹。原PDF文件不修改，笔迹随学习数据备份迁移。

## 05 · 模型配置和连接测试

### 用途
选择用于解释、问答、识题和总结的聊天模型；可以保存多套服务配置并切换。

### 用法
1. 在顶部更多设置或助读栏中打开“模型配置”，新建或选中一套配置。
2. 填写配置名称、API 地址、服务商提供的模型名称/模型 ID、API Key、温度和最大输出 Token。
3. 点击“测试连接”可直接测试当前尚未保存的表单；测试成功不代表配置已经保存，使用前仍需“保存并设为默认”。
4. 在助读栏模型下拉框切换本次使用的配置。编辑已有配置时，密钥留空会沿用已保存密钥；填写新密钥才会替换。

### 使用条件
支持 OpenAI 兼容的 Chat Completions；地址明确填写 /responses 时走 Responses 协议。API Key 不会显示在配置查询结果或完整备份中，需自行妥善保管。模型是否可用、调用费用与速率限制取决于所配置服务。

## 06 · Assistant、Master 和三种提问范围

### 用途
Assistant 与 Master 均支持按教材保存多段可命名的聊天。二者可分别清空，普通问答需要页面连接持续存在。

### 用法
- 当前原文：在 PDF 中选中一段文字，或在“教材摘录”粘贴文字，然后在下方提问。依据的是摘录及当前 PDF 页码，适合解释概念、论证或公式步骤。
- 单书全文：切换到“单书全文”，无需选中摘录，直接在下方提问框输入问题并“发送”。系统先补齐教材文字索引，再检索相关原文与页码回答，不会把整本 PDF 一次发送给模型。
- 多书联系：切换到“多书联系”，勾选参与的教材，再提问，例如“比较这两本书对进程调度的解释”。回答会保留各自教材来源。
- 保存：有 AI 回答后点击“保存解释”，将最近一条解释收入当前教材笔记；需要长期保留对话时选择 Master。
- 输入：Enter 发送，Shift+Enter 换行；进行中的问答可点击“取消问答”。

### 使用条件
必须选定可用的聊天模型。当前原文需要文字摘录或图片，多书联系需要至少一本参与教材。首次全文提问可能先等待索引/OCR。取消会停止后续前端调用，但已发出的服务请求是否停止计费取决于服务商。切书后的旧回调不会覆盖新教材界面。

### 图片摘录与图片提问

在助读栏选择当前原文、单书全文或多书联系，点击提问框旁“＋”选择教材或题目截图，也可在摘录框或提问框按Ctrl+V粘贴截图。可同时附带文字，或只添加图片后点击发送。支持PNG/JPEG/WebP，最多4张，每张20MB且不超过2000万像素；预览下可逐张移除。所选已保存模型必须支持视觉输入，纯文本模型可能拒绝图片。

图片作为本次材料保留在当前教材会话，后续提问会继续附带，直到移除或切换教材。图片不写入Master长期对话、笔记及完整备份，刷新后需重新添加。单书全文、多书联系及深度问答会先读图提取检索关键词，再将原图与检索到的教材证据一起用于回答。普通图文全文问答最多3次模型调用，深度图文问答最多4次；图片读取会增加耗时与用量。引用核验只核对教材原文，不核验图片本身；附图内容与教材出处分别展示和判断。PDF框选仍提取文字，可将截图粘贴至此使用。

### 新建、保存和命名聊天

原文、单书全文、多书联系、普通及深度问答均可使用“＋ 新建聊天”。回答结束自动保存文字，也可点“保存聊天”；新建或切换历史前会先保存当前内容。用“历史聊天”下拉框回看或继续提问，用“命名”修改名称，默认按第一条问题命名。每段会话最多1000条文字消息、合计2MB，达到限制可新建聊天。Assistant和Master各自按教材管理会话；旧Master记录首次打开时保留为“旧Master对话”。正在回答时先取消或等待完成，再切换聊天；保存失败会提示，不应关闭页面。

提问框旁的“＋”用于选择图片文件，仍支持在提问框粘贴截图。格式PNG/JPEG/WebP，单张20MB、最多4张。图片是当前临时材料，切换聊天会清空，不随文字历史保存；历史中仅保存问题和回答文字，引用卡片/检索过程不随文字会话恢复。便签中的图片继续长期保存。聊天随完整ZIP备份；含聊天会话的单书包使用格式3，需新版程序导入，仍兼容历史格式1/2。

## 07 · 导读、行间教学和划词快捷操作

### 用途
导读帮助先把握“为什么学、主要脉络、前后联系”；行间教学帮助理解作者省略的前提、中间逻辑和推导步骤。

### 用法
1. 打开“AI助读”，选“当前原文”，再选中或粘贴一段教材文字，也可添加截图并使用支持视觉的模型。
2. 点“导读”获得这段材料的学习定位和阅读路线；点“行间教学”补充省略的解释与推导。
3. PDF 选中文字后的浮动菜单还可用于解释概念、提炼要点、生成问题或联系全书。
4. 需要保留回答时点“保存解释”，然后在笔记或学习记忆中查看。

### 例子
原文说“时间片过短会增加系统开销”。行间教学可展开为：时间片越短，进程切换越频繁，保存和恢复运行状态的次数越多，因此开销增加。导读则侧重这段知识在调度主题中的位置和学习价值。

### 为什么按钮是灰色
“导读”“行间教学”目前只允许当前原文模式，需有文字摘录或图片，且没有正在运行的问答或正在读取的图片；全文 RAG 下会禁用。全文模式请在下方提问框发送问题。“保存解释”需要先有回答，“清空”需要先有对话记录。

## 08 · 普通问答、深度问答和联网查证

### 用途
普通问答适合快速查概念；深度问答适合需要补充检索和对照来源的问题；联网查证用于补充教材以外的网络资料。

### 用法
- 在单书全文或多书联系中选择“普通问答”或“深度问答”，再发送问题。
- 深度问答会显示检索、读取上下文、回答和引用核验等阶段，可点击“取消问答”。
- 勾选“联网查证”时才启用网络检索；不需要外部资料时取消勾选。
- 查看回答中的教材来源和独立网络来源；点击教材来源可回到相应 PDF 页。
- 普通及深度问答均可附图片：点击提问框旁“＋”或在提问框粘贴截图。图片数量、大小与保存范围见第06章。

### 使用条件
深度问答最多两轮补充检索、最多四次模型调用，可能比普通问答更耗时、更消耗额度。联网依赖网络与搜索服务，目前使用搜索结果摘要，并不逐个打开网页全文。普通/深度聊天不属于持久化后台任务，关闭页面会中断本次问答。

## 09 · 全文检索、向量模型和引用核验

### 用途
让全文回答有教材原文依据；不同向量模型用于改善本地检索，而不是替换聊天模型。

### 用法
- 查看回答下方的原文依据卡片：教材名称、PDF 页码、摘录，以及关键词、语义或混合检索来源。
- 通过“模型配置 → 向量模型”查看内置模型、下载预置模型或导入兼容 ONNX ZIP；激活新模型后会重建向量索引。
- 默认内置轻量向量无需下载；需要中文或多语言检索模型时再按用途选择。
- 展开“引用核验”，查看支持、部分支持、缺失引用、不支持等结果与原因；点击来源返回原文核对。

### 使用条件
索引存于本机，关键词和向量检索共同参与召回；内置轻量向量不等同于完整预训练语义模型。向量模型下载需联网和磁盘空间。没有可靠召回片段时，回答应说明证据不足；引用核验不能保证每个答案绝对正确。

## 10 · 笔记、保存解释和学习记忆

### 用途
把临时理解转为可检索、可回到来源的长期学习记录。

### 用法
- 在助读栏选“笔记”，填写正文，可附标题、标签、当前摘录和 PDF 页码，然后保存。
- 编辑、删除、置顶或搜索笔记；搜索涵盖标题、正文、摘录和标签。
- 有 AI 回答时点击“保存解释”；页边便签也会作为关联 PDF 页的笔记保存。
- 点击“导出 Markdown”导出当前教材笔记文字；页边便签中的图片需用单书或完整ZIP备份迁移。
- 顶部“学习记忆”按教材查看“正文记忆”和“习题学习记录”，从“返回来源”或“回到原题”重新进入 PDF。

### 使用条件
保存解释保留的是笔记，不会把 Assistant 对话变为 Master 历史。学习记忆以本机已有笔记和卡片为基础，不是自动生成的学习能力诊断。

## 11 · 框选识题、练习卡与掌握记录

### 用途
把教材题目整理成带答案的练习卡，记录哪些已掌握、哪些还需复习。

### 用法
1. 在 PDF 工具栏启用“框选”，圈出一道或多道题目；系统会从区域文字识别全部题目并生成答案，没有固定题目数上限。
2. 在助读栏“练习”查看卡片；可以重新识别当前框选，或手动补充问题与答案。
3. 点击卡片打开可拖动的题目悬浮窗，用上一题/下一题切换，“回到原题”返回 PDF 页。
4. 标记“已掌握”或“还需复习”，累计复习次数；卡片支持编辑和删除。

### 使用条件
自动识题需要可用的聊天模型，以及原生文字或已完成的 OCR 文字层。框选提取的是文字，不是向视觉模型上传截图。目前没有自动评分、错题归因、间隔复习算法或到期复习日程。

## 12 · 教材总览、章节总结和全书结构

### 用途
从章节层次整理知识结构。小章总结自身范围，大章汇总直属子章，全书结构再汇总各根章节。

### 用法
1. 从书架打开教材总览，左侧选章节，右侧查看学习结构与记录；需要时进入对应 PDF 页。
2. 在“本书总结模型”中选择已保存模型，再点击“生成全书结构”或某章的“生成学习结构”；每本书分别记住选择，提交后固定本次模型。
3. 先等待浏览器准备原文/OCR；显示“已提交后台生成”后，模型生成交给后端任务队列。
4. 在任务中心查看当前章节、分块和汇总进度，按需要暂停、取消或重新执行。已完成分块和章节会保留并在条件一致时复用。提交后台后，可打开其他教材继续提交，最多同时总结3本，其余排队。
5. 在已生成总结中选中一句话，点击“原文溯源”，选择候选位置跳回 PDF；可返回先前的总结文字。

### 使用条件
超长原文会分块并分层汇总，输出额度不足时会有界缩小输入重试；达到下限仍失败时需检查模型输出配置。重新生成可能复用已有完整结果，不保证清空所有缓存。总结溯源属于本地文字匹配，不是对整本总结做全面 AI 审计。

### 总结页码跳转与PDF章节总结

全书和章节总结中的PDF页码（如PDF5、PDF 5-42、PDF第5页、第5至8页）显示为按钮。范围跳到起始页开头；在PDF的溯源栏点击“返回总结”，回到原章节并定位、聚焦原页码按钮。页码需与原PDF实际页号一致，不能把总结中的书内印刷页码自动换算成PDF页码。

PDF工具栏新增“章节总结”，也可从左侧导航切到“总结”。面板可选择已保存的章节或全书总结，并通过“查看本页章节”定位当前页所属的已有总结。在面板点页码后收起面板并跳至原PDF页首，点击“返回章节总结”恢复之前所选总结及其滚动位置。尚无总结时提示到教材总览生成或导入，本面板不自动发起AI调用。

显式跳页不沿用旧阅读位置的页内偏移；短尾页补足滚动空间，允许页首顶端对齐。普通阅读位置恢复仍保留原有页内位置。

## 13 · 外部结构导入与待补充章节

### 用途
直接使用已有目录和人工总结，也能补齐被服务商审核拦截的章节。

### 用法
- 在教材总览点击“导入结构 / 总结”，选择 JSON、Markdown 或 TXT；导入本身不调用 AI。
- 标题可写 PDF 页码范围。建议使用明确、递增的 PDF 实际页序，例如以下 Markdown；下方正文作为相应章节总结：

```markdown
# 第一章 哲学概论 PDF 2-6
本章讨论哲学的基本问题和主要观点。

# 第二章 唯物论 PDF 7-11
本章梳理物质与意识的关系。
```

- 没写页码时会尝试匹配已有目录，无法匹配可能沿用前一识别页码；导入后请核对标题、层次和起始页。
- 明确审核拦截时任务会跳过该章，列为“待补充”，继续其余章节。任务“部分完成”不代表所有章节都有总结。
- 在待补充清单点击“导入本章人工总结”，选择本章 MD/TXT；只补该章，不替换整本目录。成功补齐后可重新执行全书结构以更新上级汇总。

### 使用条件
替换目录前先暂停或结束本书活动总结任务；原文准备期间也先停止准备。遇到鉴权、网络、余额或配置错误不会盲目跳章。已保存的旧总结会保留，不能确认归属的历史内容不会强行绑定到新章节。

## 14 · 任务中心、索引和断点续传

### 用途
统一查看后台索引和结构总结的进度，保留失败原因并复用已完成部分。

### 用法
- 点击“任务中心”展开队列。导入 PDF 会自动排队索引，也可手动“索引当前教材”或“索引全部教材”。
- 查看排队、运行、取消中、已暂停、已完成、部分完成、失败及已取消状态，以及章节/分块、页数和等待倒计时。
- 活动任务可取消，总结可暂停；暂停、失败、取消或部分完成后点击“重新执行”，复用可用断点。
- “查看教材”回到对应总览；“清除已结束”批量清理已完成、部分完成、失败和已取消记录，不清理暂停任务。
- 每条任务都有“删除”，暂停、排队、运行中和已结束均可删除。删除会立即移除该任务记录，停止后续处理，保留已有总结、成功分块、页面索引和待补充清单；删除后该记录不能再点“重新执行”，可从教材总览重新提交总结，或重新索引教材并复用已有成果。
- 删除运行中任务时，正在进行的模型调用或页面处理可能仍需时间退出；退出前仍会保护教材，不能立即编辑目录或替换该书数据。删除记录不保证服务商停止计费。“尚未提交后台”的原文准备请使用“取消准备”。

### 什么时候可以关页面
“尚未提交后台”的原文/OCR准备仍依赖当前页面，应等待提交完成。已提交的索引/总结可在关闭页面后继续，但后端服务必须保持运行。后端重启会把未完成任务置为暂停，需要手动重新执行；不自动无人值守续跑。

### 使用条件
后台索引读取原生文字并复用缓存，不自行运行浏览器 OCR；扫描页需在阅读、搜索或全文提问时补齐。普通聊天、深度问答和模型下载不包含在持久化任务中心中。限流时等待冷却，避免连续点击重试；暂停、取消或删除运行中任务都可能需要等待正在进行的模型请求退出。

### 多本教材同时生成结构

一本教材完成原文准备并提交后台后，可返回学习空间，打开其他教材并生成全书结构。最多同时总结3本，其余排队；任务中心可分别查看进度、暂停、取消或重新执行。索引使用独立队列。各书共享请求间隔和服务商限流冷却，并发不代表速度固定提升3倍；实际速度取决于模型服务。尚未提交的原文/OCR准备须保持当前页面，提交后可以切换教材。

结构总结支持在教材总览的“本书总结模型”中选择已保存的聊天模型，每本教材在当前设备分别记住选择；章节与全书生成均使用该模型。提交前固定本次模型，后台运行时不可切换，不影响其他书籍或助读模型。任务中心重新执行沿用原任务模型；需更换时先暂停或取消，再回教材总览选择并生成。已完成章节仍可复用，不会因换模型全部重做。

## 15 · 导出、完整备份和恢复

### 用途
保留学习成果，按需要迁移单本教材或整库数据，也可将旧版备份迁移到新版。

### 用法
- “更多设置 → 导出数据 JSON”：导出结构化学习数据，便于查看或另行处理。
- “笔记 → 导出 Markdown”：导出当前教材笔记文字，包含来源页码与摘录，不含便签图片。
- 书架教材“··· → 导出本书全部数据”：下载单书ZIP；在“导入单书备份”导入，仅新增或替换该书，详见下方。
- “更多设置 → 完整备份”：下载含数据库、教材 PDF、索引和本地向量模型的完整 ZIP。
- “更多设置 → 恢复备份”：选择该完整 ZIP，确认恢复；恢复前会生成安全快照，并检查路径、大小和校验信息。

### 使用条件
JSON 和笔记 Markdown 都不能代替完整 ZIP 恢复。API Key 不在完整备份中，恢复后按需要重新配置。恢复会替换当前项目数据；如果提示仍有请求运行或正在恢复，请稍后重试。项目没有云端自动同步、账号体系或多端冲突合并，两版也不会自动同步数据。

### 单书全部数据导入与导出

在书架每本教材的“···”菜单点击“导出本书全部数据”，下载单书ZIP。书架或“更多设置”中的“导入单书备份”可导入该ZIP。包含PDF、阅读位置、笔记、对话、高亮/手写、练习及复习记录、OCR、目录、章节/全书总结、待补充清单、总结断点、任务历史和检索分块/向量；携带相关模型配置（不含密钥）及当前设备的本书总结模型选择。

新PDF导入为一本教材；已有相同PDF时，需要确认替换该书学习数据，导入前自动在数据目录backups保存单书快照。其他教材不受影响。导入的未结束任务保持暂停，确认模型配置和密钥后手动继续；同书后台任务未结束时先暂停并等待。来源文件夹按名称匹配或新建，替换已有书时保留其当前文件夹。向量与本机当前模型不兼容时仅重建导入书的向量，不替换共享模型。

ZIP上限1GB，PDF512MB，学习数据128MB。校验格式、条目、体积、SHA256及数据归属，异常事务回滚。API Key、共享向量模型文件和未持久化的提问图片不包含在包中。单书ZIP与整库备份ZIP使用不同入口。

### 旧版数据自动兼容

本项目第一版完整ZIP仍通过“恢复备份”导入；历史单书格式1的ZIP通过“导入单书备份”导入。保留原ZIP，先在临时目录校验并升级数据库、补齐缺失字段，再替换当前数据；恢复前保存安全快照，导入后初始化失败自动回滚。高于当前程序支持范围或损坏的数据库会在替换前拒绝，不猜测其他软件或无格式说明的备份。

旧章节总结按已有目录核对标题、页码范围及层级，匹配后转换为新版范围键；没有保存目录时尝试读取原PDF书签。无法可靠匹配或与新版总结冲突的记录保留为历史总结，可在PDF“章节总结”面板选择查看、点击页码，但不自动当作当前章节。旧正文不必重新生成就可使用新版页码按钮和返回功能。

自动恢复关键词索引，补建缺失的OCR检索分块并按当前本地模型处理不兼容向量；随备份携带的本地导入模型路径会按新数据目录重定位。未结束的旧任务保持暂停，确认模型配置后可继续。旧API Key不从备份恢复，图片问答仍需支持视觉的模型；兼容过程不发起聊天模型调用。

## 16 · 布局、启动和常见问题

阅读器顶部“收起功能栏”会隐藏工具按钮和标注浮栏，保留翻页、展开入口及正在使用的工具提示；收起后仍可继续手写，也可点“结束标注”退出。点“展开功能栏”恢复操作，状态记忆在当前设备。

### 布局与启动
- 拖动 PDF 与助读之间的分隔线调整宽度；拖动摘录区和提问区分隔线调整高度；聚焦分隔线后也可用方向键调整。尺寸与折叠状态会记住。
- 依赖安装后，双击第二版目录的 start-dev.cmd 启动，或 restart-dev.cmd 重启并打开页面；第二版页面为 http://127.0.0.1:5174/。
- 桌面快捷方式安装器可创建第二版重启入口。重启会中断当前模型调用，已完成的总结分块保留，可在任务中心重新执行。
- Windows 桌面版：完整解压分发 ZIP 后双击 DubuTianxia.exe，保留相邻 _internal 目录；需要 Windows 10/11 x64 和 Edge WebView2 Runtime，无需 Python/Node。数据位于 %LOCALAPPDATA%\DubuTianxia\v2\data，与网页项目分开。原网页“完整备份”导出 ZIP 后，在桌面版“恢复备份”导入。退出会停止后台任务，需要继续时请最小化。更新只替换程序目录，保留用户数据目录。

### 常见问题
- “发送”不能点：先输入问题或添加图片，并选择可用模型；多书模式至少选一本书；等待当前请求和图片读取结束。当前原文模式还需要有效文字摘录或图片。
- “全文 RAG 模式”那一行不是可点击的模式开关。切换范围请使用上方“当前原文 / 单书全文 / 多书联系”；提问请使用下方输入框。
- “导读”“行间教学”灰色：切到当前原文并加入文字摘录或图片，再等待当前问答及图片读取结束。保存解释和清空分别需要已有回答与对话。
- 刚点提问很久没有回答：先看是否正在补齐全文索引/OCR。扫描页或大教材首次处理较慢；可查看进度或取消。
- 索引成功却没有目录：索引负责文字检索，目录来自电子书签、已保存校对目录或导入结构；无目录时到“生成 / 编辑目录”生成AI草稿并校对。
- 模型提示没有 API Key、鉴权失败或模型不存在：打开模型配置核对并测试当前表单，确认保存后再使用；不要把密钥贴到普通问答里。
- 总结失败或限流：按任务记录检查服务、余额、输出 Token 和等待倒计时；完成部分会保留，冷却后重新执行。
- 图片大小被拒绝：AI提问最多4张、每张20MB；页边便签单张及一条便签全部图片合计20MB。两类图片用途和保存方式不同。
- 删除任务后目录仍不能编辑：等待正在进行的调用退出；删除任务记录会保留已生成内容。
- 有答案但没有可靠出处：回到原文证据与引用核验区确认；检索不到证据时不要把模型推测当成教材结论。
- 页面关闭后任务停止：区分普通聊天、浏览器原文准备和已提交的后台任务；只有后者能在后端运行时继续。

### 当前能力边界
安卓平板移植采用“本地学习＋在线AI”：教材、OCR、笔记和轻量检索均在平板本地；在线AI需自行配置密钥。密钥由系统Keystore加密保存。横屏并排、竖屏上下阅读与助读，文件通过系统选择器导入/导出；单次导出上限512MB，不提供桌面FastEmbed模型管理。停止服务或系统回收会中断任务，已保存断点可重新执行。APK的可用性以构建与Android14验证结果为准。
读步天下支持本地网页和 Windows EXE 桌面窗口；桌面版为免安装目录版，没有自动更新、安装器或数字签名。已具备文本问答、本地 OCR、总结、记录和复习卡；没有语音输入/朗读、自动评分、自动复习日程或可交互知识图谱。本手册按现有实现编写，后续功能变化会同步更新。
