# 读步天下使用指南

第二版 · 入门与功能手册。用同一份教材，把阅读、提问、总结和复习连起来。

## 01 · 第一次使用：从这里开始

### 用途
快速走通“导入教材 → 阅读 → 提问 → 保存 → 复习”的完整路径。只阅读 PDF、搜索、标注和手写笔记，不需要聊天模型 API Key。

### 用法
1. 在“学习空间”点击“＋ 导入教材”，选择本地 PDF。点击书架中的“打开”进入教材总览，再点击“继续 PDF”进入阅读器。
2. 如需 AI，在“模型配置”填写服务地址、模型名称和 API Key。可先点“测试连接”，再点“保存并设为默认”。第二版的模型密钥独立配置，第一版密钥不会自动复制。
3. 阅读时点击“AI助读”。选中文字后解释局部内容；切到“单书全文”则在下方输入问题，系统检索教材原文后回答。
4. 点击“保存解释”收入笔记；或者在“练习”中打开题目卡，标记“已掌握”或“还需复习”。
5. 在“学习记忆”按教材回看内容；定期通过“更多设置 → 完整备份”下载完整 ZIP。

### 随时查阅
首页“打开使用指南”、顶部“使用指南”和阅读器工具栏的“使用指南”均打开本手册。目录可定位章节，搜索框可查找功能或使用条件；关闭手册后继续原来的页面。

## 02 · 书架、教材和文件夹

### 用途
集中管理本地教材，按学习主题分组，并从上次阅读位置继续。

### 用法
- 导入：点击“＋ 导入教材”。在某个文件夹下导入，教材会归入该文件夹；目前支持 PDF。
- 打开：点击教材行的“打开”先看总览；首页“继续学习”直接进入当前教材阅读器。
- 整理：点击“＋ 新建文件夹”；文件夹旁的更多操作可重命名、删除。教材行的更多操作可重命名、移动文件夹、查看全书结构或删除。
- 筛选：点击“全部教材”、某个文件夹或“未分类”。删除文件夹不会删除里面的教材，教材回到未分类。
- 返回：使用页面的“返回”按钮在学习空间、总览、阅读和学习记忆之间返回。

### 注意
删除教材会同时清理其关联学习数据。需要保留时先做完整备份。文件夹和教材数据保存在本机，两版项目的数据不会自动互相同步。

## 03 · PDF 阅读、目录、搜索和 OCR

### 用途
连续阅读原始 PDF，找到章节或关键词，并将扫描页转换成可选文字。

### 用法
- 翻页：连续向下滚动，或使用顶部页码输入、上一页和下一页。普通打开会恢复上次页码、页内位置和缩放；引用、搜索等指定页跳转优先。
- 定位：点击“目录”查看 PDF 书签；点击“页面”查看缩略图。缩略图上的星标可标记整页。
- 搜索：点击放大镜“书内搜索”，输入原文关键词并点击“搜索”；点击结果返回对应 PDF 页。清空或关闭搜索可结束本次搜索。
- 文字：有原生文字层的 PDF 可直接选择。扫描页会自动进行本地中英文 OCR，等待状态显示“OCR 文字可选”后再选择或框选。
- 显示：在工具栏“更多阅读工具”中缩放、恢复“适应宽度”或开启“柔和纸色”。窄阅读区可横向滚动工具栏。

### 使用条件
OCR 和全文补读可能耗时，需要本地 OCR 资源已安装。搜索最多显示 80 个匹配页面。这里的页码指 PDF 文件实际页序，可能与纸面印刷页码不同。没有 PDF 书签时，可在总览导入外部目录；目前不会自动识别整张目录图片来重建目录。

## 04 · 文字高亮、手写标注和页边便签

### 用途
在原文旁留下重点、图示和短笔记，方便回看。

### 用法
- 文字高亮：选中原文，在浮动菜单中保存高亮。通过“高亮管理”搜索、定位、改色、添加备注与标签或删除。
- 整页星标：在“页面”缩略图上点击星标；可在高亮管理中回到标记页。
- 手写：点击“标注”，选择画笔或荧光笔，调整颜色与粗细后在页面落笔。支持鼠标、触控或触控笔；“完成”退出绘制模式。
- 修改：选择橡皮擦，按住鼠标、手指或笔连续擦动，经过的位置会即时消失，松开后保存；拖动“橡皮大小”调节8—80px直径，圆圈显示范围，偏好自动记住。点击“撤销 Ctrl+Z”或使用 Ctrl+Z 撤销整次擦除。选中文字创建的高亮请在“高亮管理”中删除。
- 二合一电脑手写笔：进入“标注”后，笔尖使用当前工具；有笔尾橡皮时可翻转擦除，支持标准侧键的笔可按住侧键临时擦除、松键继续书写。勾选“仅手写笔”可防止手掌和手指写画，鼠标仍可操作；笔在操作时也会忽略触摸干扰。
- 便签：点击“便签”，给当前 PDF 页添加、编辑或删除页边文字便签。

### 使用条件
标注和便签保存在本机。手写撤销最多保留当前阅读会话的 80 步，不是跨重启的编辑历史。框选识题与手写绘制是不同工具，使用一个时会退出另一个。

手写笔按钮取决于硬件及Windows驱动向WebView2提供的笔事件；蓝牙顶部快捷按钮不属于侧键，若系统把按钮分配给其他应用，请使用工具栏橡皮擦。当前笔宽由“粗细”控制，不随压感变化。橡皮大小按屏幕CSS像素计算，PDF缩放后仍保持同样的屏幕擦除直径。

## 05 · 模型配置和连接测试

### 用途
选择用于解释、问答、识题和总结的聊天模型；可以保存多套服务配置并切换。

### 用法
1. 在顶部更多设置或助读栏中打开“模型配置”，新建或选中一套配置。
2. 填写配置名称、API 地址、服务商提供的模型名称/模型 ID、API Key、温度和最大输出 Token。
3. 点击“测试连接”可直接测试当前尚未保存的表单；测试成功不代表配置已经保存，使用前仍需“保存并设为默认”。
4. 在助读栏模型下拉框切换本次使用的配置。编辑已有配置时，密钥留空会沿用已保存密钥；填写新密钥才会替换。

### 使用条件
支持 OpenAI 兼容的 Chat Completions；地址明确填写 /responses 时走 Responses 协议。API Key 不会显示在配置查询结果或完整备份中，需自行妥善保管。模型是否可用、调用费用与速率限制取决于所配置服务。

## 06 · Assistant、Master 和三种提问范围

### 用途
Assistant 用于本次阅读中的临时解释；Master 用于按教材长期保存的学习对话。二者可分别清空，普通问答需要页面连接持续存在。

### 用法
- 当前原文：在 PDF 中选中一段文字，或在“教材摘录”粘贴文字，然后在下方提问。依据的是摘录及当前 PDF 页码，适合解释概念、论证或公式步骤。
- 单书全文：切换到“单书全文”，无需选中摘录，直接在下方提问框输入问题并“发送”。系统先补齐教材文字索引，再检索相关原文与页码回答，不会把整本 PDF 一次发送给模型。
- 多书联系：切换到“多书联系”，勾选参与的教材，再提问，例如“比较这两本书对进程调度的解释”。回答会保留各自教材来源。
- 保存：有 AI 回答后点击“保存解释”，将最近一条解释收入当前教材笔记；需要长期保留对话时选择 Master。
- 输入：Enter 发送，Shift+Enter 换行；进行中的问答可点击“取消问答”。

### 使用条件
必须选定可用的聊天模型。当前原文需要摘录，多书联系需要至少一本参与教材。首次全文提问可能先等待索引/OCR。取消会停止后续前端调用，但已发出的服务请求是否停止计费取决于服务商。切书后的旧回调不会覆盖新教材界面。

## 07 · 导读、行间教学和划词快捷操作

### 用途
导读帮助先把握“为什么学、主要脉络、前后联系”；行间教学帮助理解作者省略的前提、中间逻辑和推导步骤。

### 用法
1. 打开“AI助读”，选“当前原文”，再选中或粘贴一段教材文字。
2. 点“导读”获得这段材料的学习定位和阅读路线；点“行间教学”补充省略的解释与推导。
3. PDF 选中文字后的浮动菜单还可用于解释概念、提炼要点、生成问题或联系全书。
4. 需要保留回答时点“保存解释”，然后在笔记或学习记忆中查看。

### 例子
原文说“时间片过短会增加系统开销”。行间教学可展开为：时间片越短，进程切换越频繁，保存和恢复运行状态的次数越多，因此开销增加。导读则侧重这段知识在调度主题中的位置和学习价值。

### 为什么按钮是灰色
“导读”“行间教学”目前只允许当前原文模式且摘录非空、没有正在运行的问答；全文 RAG 下会禁用。全文模式请在下方提问框发送问题。“保存解释”需要先有回答，“清空”需要先有对话记录。

## 08 · 普通问答、深度问答和联网查证

### 用途
普通问答适合快速查概念；深度问答适合需要补充检索和对照来源的问题；联网查证用于补充教材以外的网络资料。

### 用法
- 在单书全文或多书联系中选择“普通问答”或“深度问答”，再发送问题。
- 深度问答会显示检索、读取上下文、回答和引用核验等阶段，可点击“取消问答”。
- 勾选“联网查证”时才启用网络检索；不需要外部资料时取消勾选。
- 查看回答中的教材来源和独立网络来源；点击教材来源可回到相应 PDF 页。

### 使用条件
深度问答最多两轮补充检索、最多四次模型调用，可能比普通问答更耗时、更消耗额度。联网依赖网络与搜索服务，目前使用搜索结果摘要，并不逐个打开网页全文。普通/深度聊天不属于持久化后台任务，关闭页面会中断本次问答。

## 09 · 全文检索、向量模型和引用核验

### 用途
让全文回答有教材原文依据；不同向量模型用于改善本地检索，而不是替换聊天模型。

### 用法
- 查看回答下方的原文依据卡片：教材名称、PDF 页码、摘录，以及关键词、语义或混合检索来源。
- 通过“模型配置 → 向量模型”查看内置模型、下载预置模型或导入兼容 ONNX ZIP；激活新模型后会重建向量索引。
- 默认内置轻量向量无需下载；需要中文或多语言检索模型时再按用途选择。
- 展开“引用核验”，查看支持、部分支持、缺失引用、不支持等结果与原因；点击来源返回原文核对。

### 使用条件
索引存于本机，关键词和向量检索共同参与召回；内置轻量向量不等同于完整预训练语义模型。向量模型下载需联网和磁盘空间。没有可靠召回片段时，回答应说明证据不足；引用核验不能保证每个答案绝对正确。

## 10 · 笔记、保存解释和学习记忆

### 用途
把临时理解转为可检索、可回到来源的长期学习记录。

### 用法
- 在助读栏选“笔记”，填写正文，可附标题、标签、当前摘录和 PDF 页码，然后保存。
- 编辑、删除、置顶或搜索笔记；搜索涵盖标题、正文、摘录和标签。
- 有 AI 回答时点击“保存解释”；页边便签也会作为关联 PDF 页的笔记保存。
- 点击“导出 Markdown”导出当前教材笔记。
- 顶部“学习记忆”按教材查看“正文记忆”和“习题学习记录”，从“返回来源”或“回到原题”重新进入 PDF。

### 使用条件
保存解释保留的是笔记，不会把 Assistant 临时对话变为 Master 历史。学习记忆以本机已有笔记和卡片为基础，不是自动生成的学习能力诊断。

## 11 · 框选识题、练习卡与掌握记录

### 用途
把教材题目整理成带答案的练习卡，记录哪些已掌握、哪些还需复习。

### 用法
1. 在 PDF 工具栏启用“框选”，圈出一道或多道题目；系统会从区域文字识别全部题目并生成答案，没有固定题目数上限。
2. 在助读栏“练习”查看卡片；可以重新识别当前框选，或手动补充问题与答案。
3. 点击卡片打开可拖动的题目悬浮窗，用上一题/下一题切换，“回到原题”返回 PDF 页。
4. 标记“已掌握”或“还需复习”，累计复习次数；卡片支持编辑和删除。

### 使用条件
自动识题需要可用的聊天模型，以及原生文字或已完成的 OCR 文字层。框选提取的是文字，不是向视觉模型上传截图。目前没有自动评分、错题归因、间隔复习算法或到期复习日程。

## 12 · 教材总览、章节总结和全书结构

### 用途
从章节层次整理知识结构。小章总结自身范围，大章汇总直属子章，全书结构再汇总各根章节。

### 用法
1. 从书架打开教材总览，左侧选章节，右侧查看学习结构与记录；需要时进入对应 PDF 页。
2. 选定聊天模型后，点击“生成全书结构”或某章的“生成学习结构”。
3. 先等待浏览器准备原文/OCR；显示“已提交后台生成”后，模型生成交给后端任务队列。
4. 在任务中心查看当前章节、分块和汇总进度，按需要暂停、取消或重新执行。已完成分块和章节会保留并在条件一致时复用。
5. 在已生成总结中选中一句话，点击“原文溯源”，选择候选位置跳回 PDF；可返回先前的总结文字。

### 使用条件
超长原文会分块并分层汇总，输出额度不足时会有界缩小输入重试；达到下限仍失败时需检查模型输出配置。重新生成可能复用已有完整结果，不保证清空所有缓存。总结溯源属于本地文字匹配，不是对整本总结做全面 AI 审计。

## 13 · 外部结构导入与待补充章节

### 用途
直接使用已有目录和人工总结，也能补齐被服务商审核拦截的章节。

### 用法
- 在教材总览点击“导入结构 / 总结”，选择 JSON、Markdown 或 TXT；导入本身不调用 AI。
- 标题可写 PDF 页码范围。建议使用明确、递增的 PDF 实际页序，例如以下 Markdown；下方正文作为相应章节总结：

```markdown
# 第一章 哲学概论 PDF 2-6
本章讨论哲学的基本问题和主要观点。

# 第二章 唯物论 PDF 7-11
本章梳理物质与意识的关系。
```

- 没写页码时会尝试匹配已有目录，无法匹配可能沿用前一识别页码；导入后请核对标题、层次和起始页。
- 明确审核拦截时任务会跳过该章，列为“待补充”，继续其余章节。任务“部分完成”不代表所有章节都有总结。
- 在待补充清单点击“导入本章人工总结”，选择本章 MD/TXT；只补该章，不替换整本目录。成功补齐后可重新执行全书结构以更新上级汇总。

### 使用条件
替换目录前先暂停或结束本书活动总结任务；原文准备期间也先停止准备。遇到鉴权、网络、余额或配置错误不会盲目跳章。已保存的旧总结会保留，不能确认归属的历史内容不会强行绑定到新章节。

## 14 · 任务中心、索引和断点续传

### 用途
统一查看后台索引和结构总结的进度，保留失败原因并复用已完成部分。

### 用法
- 点击“任务中心”展开队列。导入 PDF 会自动排队索引，也可手动“索引当前教材”或“索引全部教材”。
- 查看排队、运行、取消中、已暂停、已完成、部分完成、失败及已取消状态，以及章节/分块、页数和等待倒计时。
- 活动任务可取消，总结可暂停；暂停、失败、取消或部分完成后点击“重新执行”，复用可用断点。
- “查看教材”回到对应总览；“清除已结束”只清理任务历史，不删除教材总结或待补充清单。

### 什么时候可以关页面
“尚未提交后台”的原文/OCR准备仍依赖当前页面，应等待提交完成。已提交的索引/总结可在关闭页面后继续，但后端服务必须保持运行。后端重启会把未完成任务置为暂停，需要手动重新执行；不自动无人值守续跑。

### 使用条件
后台索引读取原生文字并复用缓存，不自行运行浏览器 OCR；扫描页需在阅读、搜索或全文提问时补齐。普通聊天、深度问答和模型下载不包含在持久化任务中心中。限流时等待冷却，避免连续点击重试；暂停/取消也可能需要等待正在进行的模型请求结束。

## 15 · 导出、完整备份和恢复

### 用途
保留学习成果，或者将当前完整本地数据恢复到同一项目。

### 用法
- “更多设置 → 导出数据 JSON”：导出结构化学习数据，便于查看或另行处理。
- “笔记 → 导出 Markdown”：导出当前教材笔记，包含来源页码与摘录。
- “更多设置 → 完整备份”：下载含数据库、教材 PDF、索引和本地向量模型的完整 ZIP。
- “更多设置 → 恢复备份”：选择该完整 ZIP，确认恢复；恢复前会生成安全快照，并检查路径、大小和校验信息。

### 使用条件
JSON 和笔记 Markdown 都不能代替完整 ZIP 恢复。API Key 不在完整备份中，恢复后按需要重新配置。恢复会替换当前项目数据；如果提示仍有请求运行或正在恢复，请稍后重试。项目没有云端自动同步、账号体系或多端冲突合并，两版也不会自动同步数据。

## 16 · 布局、启动和常见问题

### 布局与启动
- 拖动 PDF 与助读之间的分隔线调整宽度；拖动摘录区和提问区分隔线调整高度；聚焦分隔线后也可用方向键调整。尺寸与折叠状态会记住。
- 依赖安装后，双击第二版目录的 start-dev.cmd 启动，或 restart-dev.cmd 重启并打开页面；第二版页面为 http://127.0.0.1:5174/。
- 桌面快捷方式安装器可创建第二版重启入口。重启会中断当前模型调用，已完成的总结分块保留，可在任务中心重新执行。
- Windows 桌面版：完整解压分发 ZIP 后双击 DubuTianxia.exe，保留相邻 _internal 目录；需要 Windows 10/11 x64 和 Edge WebView2 Runtime，无需 Python/Node。数据位于 %LOCALAPPDATA%\DubuTianxia\v2\data，与网页项目分开。原网页“完整备份”导出 ZIP 后，在桌面版“恢复备份”导入。退出会停止后台任务，需要继续时请最小化。更新只替换程序目录，保留用户数据目录。

### 常见问题
- “发送”不能点：先输入问题并选择模型；多书模式至少选一本书；等待当前请求结束。当前原文模式还需要有效摘录。
- “全文 RAG 模式”那一行不是可点击的模式开关。切换范围请使用上方“当前原文 / 单书全文 / 多书联系”；提问请使用下方输入框。
- “导读”“行间教学”灰色：切到当前原文并加入摘录，再等待当前问答结束。保存解释和清空分别需要已有回答与对话。
- 刚点提问很久没有回答：先看是否正在补齐全文索引/OCR。扫描页或大教材首次处理较慢；可查看进度或取消。
- 模型提示没有 API Key、鉴权失败或模型不存在：打开模型配置核对并测试当前表单，确认保存后再使用；不要把密钥贴到普通问答里。
- 总结失败或限流：按任务记录检查服务、余额、输出 Token 和等待倒计时；完成部分会保留，冷却后重新执行。
- 有答案但没有可靠出处：回到原文证据与引用核验区确认；检索不到证据时不要把模型推测当成教材结论。
- 页面关闭后任务停止：区分普通聊天、浏览器原文准备和已提交的后台任务；只有后者能在后端运行时继续。

### 当前能力边界
安卓平板移植采用“本地学习＋在线AI”：教材、OCR、笔记和轻量检索均在平板本地；在线AI需自行配置密钥。密钥由系统Keystore加密保存。横屏并排、竖屏上下阅读与助读，文件通过系统选择器导入/导出；单次导出上限512MB，不提供桌面FastEmbed模型管理。停止服务或系统回收会中断任务，已保存断点可重新执行。APK的可用性以构建与Android14验证结果为准。
读步天下支持本地网页和 Windows EXE 桌面窗口；桌面版为免安装目录版，没有自动更新、安装器或数字签名。已具备文本问答、本地 OCR、总结、记录和复习卡；没有语音输入/朗读、视觉模型直接读图、自动评分、自动复习日程或可交互知识图谱。本手册按现有实现编写，后续功能变化会同步更新。
