封存日期：2026-10-29（Asia/Shanghai）。版本标识：`v1-final`。

本版本为当前功能与数据的归档基线，不代表所有已知问题均已解决，也不是 Windows EXE 安装版。功能范围见 [功能清单](../features.md)。后续开发应在现有项目继续，保留此封存包用于回溯与恢复。

## 封存内容

- 当前源码、启动脚本、依赖声明与锁文件、专题文档及 Git 历史备份。

- 本地数据及备份仅保存在本机，不上传 GitHub；凭据不进入源码包和数据包。

## 已知边界

- 封存时存在内容审核导致的待补充章节及失败/部分完成任务，原样保留；后续可人工补充并重建上级汇总。
- 模型、网络及内容审核限制仍取决于服务商。
- 已提交的后台任务需要后端和电脑运行；重启后未完成任务需手动重新执行。
- 恢复完整备份不恢复 API Key；须重新配置。完整数据包含私人教材和学习数据，应妥善保存。
- 源码恢复需要安装 Python/Node 依赖；本地向量模型随数据包保存。

实际封存提交、文件校验值和验证结果以本地归档目录中的 manifest.json、验证报告和 SHA256SUMS.txt 为准。
