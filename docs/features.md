## 2. PDF 阅读、文字识别与定位

实现：[PdfReader.tsx](../apps/web/src/PdfReader.tsx)、[ocr.ts](../apps/web/src/ocr.ts)、[pdfOutline.ts](../apps/web/src/pdfOutline.ts)。

- PDF.js 连续纵向阅读，附近页面按需渲染。
- 页码输入、上一页、下一页、总页数和当前页跟随。
- 缩放 50%—300%，恢复适应宽度；柔和纸色开关。
- 页面缩略图导航、当前页跟随、页面星标切换。
- 可收起的页面/目录共享侧栏；从 PDF 自带书签读取嵌套目录和目标页码。
- 教材总览可使用导入目录；没有书签时可通过外部结构文件补充目录。
- 原生文字层选择、复制、一键送入助读摘录区。
- 文字不足的页面自动执行本地中英文 OCR，生成可选文字层，显示识别进度并缓存文本。
- 书内全文关键词搜索，忽略部分空白差异，逐页补读文字/OCR，显示页码与片段并跳转。
- 搜索显示已检索页数，可关闭/取消/清空；当前最多显示 80 个匹配页面。
- PDF 矩形框选提取区域文字，交给自动识题流程；支持原生文字与已建立的 OCR 文字层。
- 高亮、笔记、问答引用、章节及总结溯源结果均可返回对应 PDF 页码。

目录来自 PDF 书签或导入结构，目前没有“扫描整本目录图片并自动重建目录”的独立功能。框选传递的是文字，不是向模型上传图片。

## 5. AI 解释与教材问答（已实现，勿重复新增）

实现：[main.tsx](../apps/web/src/App.tsx) 的 `runAsk`、`startReadingAssist`，[main.py](../apps/api/reader_next_api/main.py) 的 `/api/chat/stream`，[providers.py](../apps/api/reader_next_api/providers.py)。

- Assistant：本次阅读中的临时解释与问答。
- Master：按教材长期保存问答历史；两种模式可分别清空对话。
- 选中文字快捷操作：解释概念、提炼要点、生成理解问题及联系全书。
- 导读：为什么学、核心脉络、前后知识关系。
- 行间教学：解释省略的中间逻辑与推导步骤。
- 三种提问范围：当前选择/粘贴原文、单书全文、多书联系。
- 当前原文模式依据摘录及当前页回答；单书模式自动检索教材原文。
- 多书模式选择参与教材，跨书检索并比较一致、互补和分歧，分别保留出处。
- 带出处回答：教材名称、PDF 页码、检索摘录与可点击的来源页定位。
- 可选联网查证，显示网络标题、链接及摘要，与教材引用分开展示。
- 普通问答与深度问答切换；流式输出、进度、取消和错误提示。
- 已有全书总结时可加入概览上下文；不把全部 PDF 一次塞入问答请求。
- AI 回答和总结以标题、要点、概念卡、关系和引用标签呈现，兼容旧 Markdown 表格。
- 输入框 Enter 发送、Shift+Enter 换行；缺少模型/原文/参与教材时限制发送。

联网查证目前读取搜索结果摘要，不是逐个打开网页全文进行事实审计。普通问答和深度问答需要页面连接存续，不属于后台任务。

## 6. 本地 RAG、向量模型与深度问答

实现：[rag.py](../apps/api/reader_next_api/rag.py)、[repository.py](../apps/api/reader_next_api/repository.py)、[embedding_models.py](../apps/api/reader_next_api/embedding_models.py)、[ragIndex.ts](../apps/web/src/ragIndex.ts)、[reading_agent.py](../apps/api/reader_next_api/reading_agent.py)。

- 页面文字分块与重叠，SQLite FTS5 关键词检索、本地向量余弦检索及 RRF 融合排序。
- 索引、原文块和向量保存在本机，无需独立向量数据库。
- 内置 384 维轻量特征向量，无需下载；它不是完整的预训练语义模型。
- 可选 FastEmbed 模型，预置 BGE Small 中文与 Multilingual MiniLM。
- 在线下载模型、本地兼容 ONNX ZIP 导入、模型列表、激活及索引重建。
- PDF/OCR 文本写入后更新索引；全文问答前补齐缺失页面，显示读取/OCR/完成进度。
- 单书或所选多书检索，展示已索引页数、片段数及关键词/语义/混合/上下文来源类型。
- 深度问答最多两轮补充检索，每轮最多两条查询及两处页上下文读取。
- 深度问答最多四次模型调用：两次计划、一次回答、一次引用核验。
- 深度问答仅能读取所选书籍的已召回页及相邻页，不能任意访问文件或执行命令。
- 无效计划回退已有证据回答；证据不足时明确说明，支持过程记录、超时与取消。

深度问答限额和阶段超时见 [reading-agent.md](reading-agent.md)。FastEmbed 需要相应依赖与模型文件；切换模型不等于切换聊天模型。

## 7. 引用核验与总结原文溯源

实现：[citation_verification.py](../apps/api/reader_next_api/citation_verification.py)、[main.tsx](../apps/web/src/App.tsx) 的 `findSummarySources`、`locateSummarySources`。

- 全文问答后提取结论与页码引用，并对照本次实际检索证据核验。
- 核验状态：支持、部分支持、缺失引用、不支持；显示原因、证据及来源按钮。
- AI 核验失败时保留本地文字匹配结果与提示。
- 多书引用按教材及页码匹配，分别展示来源。
- 在章节/全书总结中选择文字，查询相关原文位置，显示多个候选片段。
- 原文溯源上一处/下一处跳转，并返回先前选中的总结文字。

总结溯源是本地匹配，不是对每条总结结论的全面 AI 审核。引用核验也不保证模型答案绝对正确；当前没有独立的全书总结质量审计报告。

## 8. 练习、自动识题与掌握记录（已实现基础能力）

实现：[main.tsx](../apps/web/src/App.tsx) 的 `makeFlashcardsFromExcerpt`、`markCard`，[main.py](../apps/api/reader_next_api/main.py) 的 `/flashcards` 路由。

- 从选中原文执行“生成问题”，产出理解检查问题和简要答案。
- 框选教材题目区域，自动识别其中全部问题并生成答案，没有固定题目数上限。
- 重新识别当前框选内容，显示本次识题数量。
- 手工补充问答卡片；卡片编辑、删除及按教材持久化。
- 卡片打开右侧可拖动悬浮窗，显示问题与答案，支持上一题、下一题及关闭。
- 标记“已掌握”或“还需复习”，累计复习次数。
- 从卡片回到原题所在 PDF 页，在学习记忆中查看记录。

当前是问题/答案卡与人工掌握记录，没有完整的提交作答—自动评分—错题归因流程，也没有间隔重复算法、到期复习队列或自动生成复习日程。

## 9. 章节与全书学习结构

实现：[chapterSummary.ts](../apps/web/src/chapterSummary.ts)、[summary_tasks.py](../apps/api/reader_next_api/summary_tasks.py)、[summaryImport.ts](../apps/web/src/summaryImport.ts)。

- 基于目录深度和页码确定章节范围，小章总结自身原文，大章汇总直属子章节，全书再汇总各根章节。
- 章节/全书生成及重新执行；已存在的完整章节会被复用，“重新生成”不保证强制清除全部缓存。
- 准备范围内完整原文及 OCR，保留 PDF 页码，超长单页也会拆分。
- 原文约 7000 字符分块，约 10000 字符分组分层汇总，最多四层。
- 输出额度耗尽时有界二分输入，最多递归三层，过小仍失败时提示调整输出额度。
- 成功块和中间汇总即时存入 SQLite 断点，最终章节单独保存。
- 断点键包含原文、提示、模型配置与页码；变化时不复用对应分块。
- 后端独立生成、暂停/取消/重新执行，成功块及章节保留，任务进度显示阶段。
- 总结遵循模型配置的最大输出 Token（配置上限 16384），失败残缺文本不作为成功块保存。
- 明确区分输出上限、上下文限制、连接中断、鉴权/配置、余额、限流及内容审核错误。
- 连接中断、超时、临时网关等有界重试；识别流未完成及 Responses 最终正文，避免误存成功或重复增量。
- 总结请求默认至少间隔 3 秒；限流后提高间隔、30/60 秒退避，遵循适用 Retry-After 并保留进程内冷却。

### 审核拦截与待补充

- 明确的内容审核拒绝仅跳过当前章节，继续其余章节；其他错误不盲目跳过。
- 保留被拦截章节的已有总结，持久化待补充章节和页码。
- 上级汇总仅使用成功材料，附上确定性的缺失清单；无材料时不调用模型凭空补写。
- 任务显示“部分完成”，处理进度不等于总结覆盖率。
- 目录待补充标记、教材当前缺失清单、任务执行时的历史缺失清单。
- 待补充项单独导入本章 MD/TXT 人工总结，不替换目录或全书内容。
- 成功保存对应章节后清除待补充标记；重新执行重建不完整上级汇总。
- 清理任务历史不删除待补充清单，删除教材时级联清理。

### 外部结构与总结导入

- JSON、Markdown、TXT 本地导入，不调用模型。
- 识别章节标题、嵌套层次、正文总结和可选 PDF 起止页码。
- 未写页码时尝试匹配现有书签；无法匹配时继承前一识别页码。
- 导入目录、全书总结及章节总结；已提供的章节可供后续汇总复用。

详细格式与恢复说明见 [summary-import.md](summary-import.md)。目前没有快速/标准/精读三档、生成前费用预估或可交互知识关系图。

## 10. 持久化后台任务中心

实现：[background_tasks.py](../apps/api/reader_next_api/background_tasks.py)、[summary_tasks.py](../apps/api/reader_next_api/summary_tasks.py)、[main.tsx](../apps/web/src/App.tsx)。

- PDF 导入自动排队索引；手动索引当前教材或全部教材。
- 索引逐页读取原生文字、复用已有页面、显示进度及结果统计。
- 后台索引不自行运行浏览器 OCR，扫描页需要阅读/搜索/问答准备阶段补充。
- 索引和结构总结共用单工作线程持久化队列，同书避免重复活动总结任务。
- 任务中心展示排队、运行、取消中、已暂停、已完成、部分完成、失败及已取消状态。
- 显示教材、任务名称、当前章节/分块/汇总、进度、更新时间、错误和限流倒计时。
- 总结准备阶段单独显示“尚未提交后台”，支持取消准备。
- 活动任务取消；总结暂停；暂停/失败/取消/部分完成任务重新执行；清理已结束任务。
- 总结任务可以返回教材查看，当前教材结果通过轮询刷新。
- 关闭页面后已提交任务继续；后端进程退出后不能继续，重启将未完成任务置为暂停。
- 重新执行复用已完成页面、章节和分块；暂停/取消受在途模型响应和超时约束。

任务中心不包含普通聊天、深度问答、模型下载等所有耗时操作。详见 [background-tasks.md](background-tasks.md)。

## 11. 模型配置与凭据

实现：[main.tsx](../apps/web/src/App.tsx) 的 `ModelSettings`、[domain.py](../apps/api/reader_next_api/domain.py)、[credentials.py](../apps/api/reader_next_api/credentials.py)、[providers.py](../apps/api/reader_next_api/providers.py)。

- 多聊天模型配置新增、编辑、删除、默认模型设置，助读中选择模型。

- OpenAI-compatible Chat Completions 和显式 `/responses` 两种协议。
- 保存配置连接测试；未保存表单也可直接测试，不改变默认配置或凭据。

- 查询不回传密钥，密钥不进入 SQLite、任务参数及备份。

目前请求为文本及检索上下文；未实现图片/视觉问答、语音识别或朗读模型接口。

## 12. 本地数据、导出与备份恢复

实现：[repository.py](../apps/api/reader_next_api/repository.py)、[full_backup.py](../apps/api/reader_next_api/full_backup.py)、[main.py](../apps/api/reader_next_api/main.py)。

- SQLite 持久化教材元数据、文件夹、阅读位置、OCR、索引、目录、总结、断点、待补充项、任务、对话、笔记、高亮及卡片。
- PDF 文件及向量模型保存本机；支持 `READER_NEXT_DATA` 指定数据根目录。

- 完整 ZIP 备份包含数据库、教材、索引与本地向量模型及配置，不包含 API Key。
- 备份清单包含文件路径、体积及 SHA-256；恢复前检查格式、路径、数量及大小限制。
- 恢复前创建安全快照；恢复后重新初始化数据访问和后台任务。
- 删除教材时清理关联数据；Git 排除本地数据、PDF、模型、凭据、日志、依赖和构建产物。

JSON 导出不是完整 ZIP 恢复入口；项目没有云端同步、账号体系或多端冲突合并。

实现：[main.tsx](../apps/web/src/App.tsx)、[PdfReader.tsx](../apps/web/src/PdfReader.tsx)、各布局 CSS、根目录启动脚本。

- 临时状态/警告/错误自动消隐，后台任务失败历史保留。

- `restart-dev.cmd` 核对进程归属后重启本项目 8789/5173 服务，隐藏运行、等待就绪并打开页面。
- 桌面“重新启动读步天下”快捷方式安装器；同名快捷方式不覆盖。
- 重启脚本 `-ValidateOnly` 依赖检查，日志保存在忽略目录。

重启脚本是开发服务入口，不是已打包安装的 Windows 桌面应用；重启会中断当前模型调用。
